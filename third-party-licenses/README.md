# Third-party licenses

LessHeadCMS itself is licensed under `AGPL-3.0-or-later` (see `../LICENSE`). This folder holds the license texts of the
third-party libraries that are part of this deployed application: one file per library, each with a short header (name,
version, license, project link) followed by the full license text.

Versions are the ones installed at the time of the audit (2026-10-08).

22 third-party components: PHP packages in `vendor/` and JavaScript libraries or embedded components contained in the
bundles in `assets/`.
